Misaki Milestone 2 — experimental CPU + memory foundation.
Copy the Misaki and MisakiTests folders into your existing repository, merging folders.
This is a minimal four-opcode CPU interpreter and sparse byte memory, NOT a PS4 firmware emulator or PS4 menu.
Run your existing GitHub Actions build. Unit tests require an iOS simulator test job, not just xcodebuild build.
No proprietary firmware, keys or protected binaries are included.
